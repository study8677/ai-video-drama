# 《百亿死对头困死货梯，门外竟是共同杀手》微短剧剧本

## 核心档案
- **原著母题**：萨基《闯入者》（*The Interlopers*, 1919，作者1916年逝世，100%公版脱敏魔改）
- **赛道标签**：都市悬疑暗黑 / 商战黑色幽默 / 第一人称男频
- **适配形态**：Colab MiniMax-H3 原生音画一体版（3集 × 4镜 = 12镜，约 62 秒竖屏 `480x864`）：见 [episodes.json](episodes.json)

## 一句话卖点
争夺80亿地皮的两个商战死对头被困断网货梯68小时，濒死之际喂水救命、按血手印签下平分和解书；终于盼来撬门脚步声，却发现门外站着的是他俩各自花500万买凶灭口的同一伙杀手！

## 人物弧线
- **陆沉（S1）**：36岁科技新贵，从冷酷商战狼 → 绝境递出救命水的人性回暖 → 看见自己雇来的杀手时的彻底崩塌。
- **赵坤（S2）**：42岁地产大佬，右腿被铁架压断，从狠辣猜忌 → 濒死和解 → 吐露“我也花500万请了同一伙人”的绝望苦笑。
- **刀疤男（S3）**：38岁地下杀手头目，亮出两笔500万转账记录，以极度冷静的黑色幽默完成终极收割。

## 分集大纲（MiniMax-H3 3集高能闭环）
- **第1集：负四层铁棺材（4镜 · LOC1 破损货梯内）**：钢缆坠断后两人困在断网货梯互相指责设局 → 58小时缺氧断水，陆沉把最后两口水喂给昏迷的赵坤 → 两人含泪按血手印签下80亿平分和解书。
- **第2集：救兵降临与致命错愕（4镜 · LOC1 破损货梯内）**：门外传来急促脚步声与撬棍声，两人狂喜大喊“是我的人来了” → 强光破门，刀疤男拎着汽油桶现身，陆沉与赵坤同时认出对方当场魂飞魄散。
- **第3集：两笔五百万的死局（4镜 · LOC1 货梯口）**：陆沉举着血手印协议嘶喊取消单子 → 赵坤绝望坦白他也花了五百万买凶 → 刀疤男亮出两笔500万转账冷笑收全款 → 泼油点火，打火机坠落瞬间黑屏留白。
